# `near_topic` 题集怎么写的（2026-10-30）

这一批题的性质决定了它的可信度全在**写法**上：`near_topic` 的意思是"语料有相关章节，缺的正是
被问的那个事实"。写题的人如果先看检索结果再写，写出来的必然是"系统答错的题"，
测出来的拒答率就是自己挑的。

## 一、写法：属性缺口，不看检索

不做"看系统答错了什么→把它记成该拒"，而是反过来按**属性**出题。标准、政策、实施方案、
图集这几类文件能回答的属性是有限且稳定的（技术要求、评价方法、补贴标准、试点名单、
验收流程），反过来，它们几乎不写：造价细目、人工工日、税率、保险费率、就业人数、
品牌型号、投诉渠道、排名、产值、贷款贴息、社保。于是：

1. 只读**文件名**（75 份，公开元数据）确定语料覆盖哪些主题；
2. 对每个主题套一条"这类文件通常不写"的属性，写成一句用户会真的问出口的话；
3. 定稿前**不跑检索**，也不打开任何候选片段。

共写了 34 条，草稿留在 `eval/refuse-near-topic-draft-1.json`（22 条）与
`eval/refuse-near-topic-draft-2.json`（12 条）——两份都只有 `question` 与核验用关键词，
**没有检索结果**，可以据此检查"写题时到底看没看过系统输出"。

## 二、核验：子串，不用向量也不用 BM25

写完才核验，且核验手段与检索无关：`scripts/find_gold_by_text.py` 拿"答案一定会出现的那个词"
（单位、名称、取值类型）在**全文**里做子串匹配，命中 0 条才算"库里没有"。

与第四十七轮 B 批同一套方法，理由也相同：向量检索与 BM25 会给你"主题最近的一条"，
那永远非空，没法用来判"有没有"。

核验结果：**保留 21 条，剔除 13 条**。剔除的都是"其实答得出"：

| 被剔的问句 | 子串核验命中 | 为什么答得出 |
|---|---|---|
| 装配式装修的房子保修期是几年？ | `保修期限` | JGJ/T 491—2021 第 8.0.2 条：不应低于 5 年，缺陷责任期宜 2 年 |
| 楼板撞击声要控制到多少分贝？ | `撞击声` / `dB` | GB 55038—2025 有计权标准化声压级差条文；设计导则部品表列隔声性能(dB) |
| 胶粘剂 VOC 含量限值是多少？ | `VOC` / `游离甲醛` | GB 50325—2020 第 3.5、3.6 条与限量表 |
| 装配化装修试点企业一共多少家？ | `试点企业` / `12家` | 浙建管发〔2024〕56 号：第一批 12 家 |
| 吊顶检修口要留多大？ | `检修口` | 验收暂行规定有检修口条目 |
| 墙板厚度允许偏差多少毫米？ | `允许偏差` | 验收暂行规定有偏差表 |
| 项目要不要走政府采购招标？ | `招标` / `政府采购` | 政策文件有招标与政府采购要求 |
| 补贴款交完材料多久到账（绍兴）？ | `个工作日内` | 只有宁波鄞州写了"30 个工作日内拨付"——跨地域混答，语义不清，剔除 |
| 房子转手算不算绿色建筑加分？ | `绿色建筑` / `加分` | 评价标准有加分项，"二手转让"无对应，题意含混，剔除 |
| 岩棉密度要求多少？ | `密度` | 命中的是"中密度板"，词形误命中；无法用子串证明缺失，剔除 |
| 装配化装修能少产生多少建筑垃圾？ | `建筑垃圾` / `吨` 均未命中答案 | **错标**：语料原文是「现场固废物不仅减少了 70%」，同义词没覆盖到，见下 |

最后一条是被**判官**抓出来的，不是被核验抓出来的。它当时已进题集，判官对它的回答是
「片段 1 明确记载『现场固废物不仅减少了 70%』，提供了具体数值」——判「可」。逐条核对后
判官是对的，我错在拿「建筑垃圾减量」当检索词，而语料用的是「固废物」。

这条比前面 12 条重要：**子串法 0 命中只能证明"我没想到的那个词不在库里"，证明不了
"库里没有"**。同义词覆盖不到，就会把答得出的题记成该拒。所以这批题的"该拒"永远是
相对于"我核验过的那些词"而言的。

`岩棉密度` 那条值得单独记：**子串法证伪的能力弱于证明的能力**。命中 0 条能说明"库里没写"，
但命中一堆"看着像"的（密度板≠岩棉密度）时，这个方法给不出结论——只能剔除，
不能反向判"其实有"。所以这批判"该拒"的题，宁可少留。

保留的 21 条按语料主题分散：政策补贴 6、标准条文 5、施工与验收 4、市场与造价 3、
组织与人力 3。没有集中在某一类上，避免"闸门只在某类题上看起来有效"。

## 三、这一批的偏差，写清楚

1. **写题与核验是同一个人**。核验用的关键词是我自己选的——选哪些词决定了"命中 0 条"
   有多容易达到。真正的方法学要求是另一个没参与写题的人拿同样的问句独立核验一遍。
   这一步没做，只能记为已知偏差。
2. **剔除的 12 条不进任何统计**。它们其实是"库内可答"的题目，本可以拿去做金标；
   但这批的定位是库外集，混进去会让类别统计失去意义。留在本文档里备查。
3. **判据仍是"字面缺失"**。库里完全没有提到，与"提到了但没有给定值"，在子串法下都是 0 命中——
   前者是真没有，后者是"有上位要求、缺具体取值"，两者对判官难度不同。21 条里后者大约
   占 9 条（资质等级、检测机构、保修起算、投诉渠道等），这是有意的：`near_topic` 的原型
   正是"章节相关、取值缺失"。
